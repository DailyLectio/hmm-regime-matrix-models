## What to Watch For

### During HMM Processing (Step 4)

You'll see console output like this:

```
[NQ] Loading FULL export file (no rolling window)...
[NQ] RTH data: 280,000 bars across 750 trading days
[NQ] Resampling to 5-min...
[NQ] 5-min bars: 60,000
[NQ] Building feature matrix...
[NQ] Fitting HMM on 59,500 bars... (this may take 2-5 minutes)
```

**This is normal.** The HMM fit on 750 days of data takes time.

### Expected Warnings

You might see:
```
/usr/lib/python3.x/site-packages/sklearn/utils/extmath.py:...
RuntimeWarning: invalid value encountered in scalar divide
```

**This is harmless.** It's a numerical precision warning from the HMM library.

## Troubleshooting

### Issue 1: "Module 'hmmlearn' not found"

**Fix:**
```batch
pip install hmmlearn --break-system-packages
```

### Issue 2: HMM still produces 4,705 rows

**Cause:** You didn't use the `--full-history` flag.

**Fix:** Make sure you run:
```batch
python HMMWatchdog_V3D.py --once --full-history --symbol BOTH
```

Not just:
```batch
python HMMWatchdog_V3D.py --once --symbol BOTH
```

### Issue 3: "All HMM fit attempts failed"

**Cause:** Not enough data or numerical instability.

**Fix:** Check that export files have at least 6 months of data. If less, the HMM cannot reliably fit 4 states.

### Issue 4: Process takes longer than 10 minutes

**Normal if:**
- You have more than 1 year of data
- Your CPU is older/slower
- Other programs are running

**Not normal if:**
- Process hangs for 30+ minutes with no output
- CPU usage is 0%

If hung, press Ctrl+C, restart, and try one instrument at a time:
```batch
python HMMWatchdog_V3D.py --once --full-history --symbol NQ
python HMMWatchdog_V3D.py --once --full-history --symbol ES
```
