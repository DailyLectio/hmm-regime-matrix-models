## Output File Schema

The `RegimeMatrix_Full.csv` contains these key columns:

### Core Identifiers
- `session_key` — Join key (e.g., "NQ_20260424_10:35")
- `TimestampET` — Checkpoint timestamp
- `Symbol` — NQ or ES

### Input Layers
- `MacroRegime` — Stage A classification (TREND, ROTATION, BALANCE)
- `MacroPlaybook` — Stage A playbook state
- `HMMRegime` — Stage B classification (TrendUp, TrendDown, Balance, Transition)

### Supervisor Scores
- `TrendExpansionScore` — Raw score (0-100)
- `KalmanSmoothedScore` — Smoothed score after Kalman filter
- `ConflictScore` — Disagreement between macro and HMM (0.0-1.0)

### Final Classification
- `FinalRegime` — One of: TREND_EXPANSION, TREND_COMPRESSION, ROTATION_LIQUID, ROTATION_ILLIQUID, TRANSITION
- `FinalDirection` — LONG, SHORT, or NEUTRAL
- `RegimeConfidence` — Confidence score (0-100)
- `ReasonCode` — Why this regime was chosen

### Bot Permissions (Boolean Flags)
- `AllowExpansion`, `AllowMomo`, `AllowPine`, `AllowADX_DI`, `AllowSniper`
- `AllowLong`, `AllowShort`, `AllowFadeLong`, `AllowFadeShort`

### Position Sizing
- `ExpansionSizePct`, `MomoSizePct`, `PineSizePct`, `ADX_DISizePct`, `SniperSizePct`
- Values: 0-100 (percentage of max position size)

### Metadata
- `Phase` — Session phase (OPENING_AUCTION, POST_IB_MACRO, etc.)
- `StateAgeBars` — How many consecutive bars in this regime
- `StaleDataFlag` — 0 in batch mode (always fresh)

## Common Issues and Fixes

### Issue 1: "NQ_Macro_Regimes_V3D.csv not found"
**Fix:** Run `Run_V3D_Pipeline.bat batch` first to generate Stage A and B outputs.

### Issue 2: "Junction not found"
**Fix:** Run `V3D_Setup_Junction.bat` as administrator.

### Issue 3: "KeyError: 'session_key'"
**Fix:** Your macro or HMM CSV is missing the `session_key` column. Re-run the pipeline with the latest versions of MacroRegimeBuilder and HMMWatchdog.

### Issue 4: Merge produces zero rows
**Fix:** The `session_key` values don't align between Stage A and Stage B. This usually means:
- One stage was run on a different date range
- One stage failed silently and produced incomplete output
- Re-run BOTH Stage A and Stage B in batch mode to sync them

### Issue 5: Low row count (e.g., only 1,000 rows)
**Fix:** Your macro CSV only contains recent data. Re-run MacroRegimeBuilder in batch mode on the full export file.
