## REGIME STATE MEANINGS

**TREND_EXPANSION** (rare - 0.9%)
- Confirmed breakout, strong velocity
- Expansion bot allowed
- Highest conviction trades

**TREND_COMPRESSION** (9-11%)
- Directional but slowing
- Momentum + Sniper allowed
- Good win rate

**ROTATION_LIQUID** (32-37%)
- Tradable two-sided chop
- Fader + ADX_DI allowed
- Most opportunities

**ROTATION_ILLIQUID** (50-52%)
- Dead chop, narrow range
- ALL BOTS OFF
- Stay out

**TRANSITION** (5-6%)
- Macro/HMM conflict
- ALL BOTS OFF
- Danger zone

## TROUBLESHOOTING

**HUD shows STALE during market hours**
→ Python supervisor not running
→ Latest.csv not being updated
→ Check Python windows for errors

**HUD shows UNKNOWN at 09:35**
→ Stage A or B not producing data
→ Check export files exist and are updating
→ Restart pipeline

**Bots enabled but not trading**
→ Check HUD shows Allow{Bot} = ON
→ Check bot parameters (ADX floor, CI max, etc.)
→ Check account is live (not SIM)

**Python windows show errors**
→ Take screenshot
→ Check file paths exist
→ Verify pandas/numpy/hmmlearn installed
